I'm **Himanshu Kumar Singh**, a Cybersecurity Engineering student focused on building a career in Security Operations and Defensive Security.

My primary interests include understanding how cyber threats operate, investigating suspicious activities, analyzing security logs, and developing practical threat detection capabilities.

I believe cybersecurity is not just about knowing tools — it's about understanding what's happening behind the alerts.

- 🔐 Interested in **SOC Operations, Threat Detection & Incident Response**
- 🌐 Strengthening Networking, Linux and Windows Security fundamentals

- 🛠️ Building hands-on cybersecurity projects and lab environments
- 📚 Continuously learning through practical labs and security research

**Current Mission:** Become a job-ready SOC Analyst and contribute to real-world security operations.
